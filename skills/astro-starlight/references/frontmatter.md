# Frontmatter Reference

Use for page-level configuration in Markdown and MDX files.

Source docs: `reference/frontmatter.md`.

## Core Fields

```md
---
title: About this project
description: Learn more about the project.
---
```

| Field | Type | Purpose |
| --- | --- | --- |
| `title` | `string` | Required. Page H1/title metadata/browser title. |
| `description` | `string` | Search/social metadata. |
| `slug` | `string` | Override content collection ID/route. Use sparingly. |
| `editUrl` | `string | boolean` | Override or disable global edit link. |
| `head` | `HeadConfig[]` | Add page-specific head tags. |
| `tableOfContents` | `false | { minHeadingLevel?, maxHeadingLevel? }` | Override TOC. |
| `template` | `'doc' | 'splash'` | Splash is wide landing layout. |
| `hero` | `HeroConfig` | Hero for splash/landing pages. |
| `banner` | `{ content: string }` | Announcement banner. |
| `lastUpdated` | `Date | boolean` | Override git date/global setting. |
| `prev`, `next` | `boolean | string | { link?, label? }` | Footer pagination controls. |
| `pagefind` | `boolean` | Include/exclude page from Pagefind. |
| `draft` | `boolean` | Exclude docs page from production builds. |
| `sidebar` | `SidebarConfig` | Autogenerated sidebar behavior. |

## Table of Contents

```md
---
title: API
tableOfContents:
  minHeadingLevel: 2
  maxHeadingLevel: 4
---
```

Disable:

```md
---
title: Landing
tableOfContents: false
---
```

## Splash and Hero

```md
---
title: My Project
template: splash
hero:
  title: My Project
  tagline: Fast docs for a useful product.
  image:
    alt: Project logo
    file: ~/assets/logo.png
  actions:
    - text: Get started
      link: /getting-started/
      icon: right-arrow
    - text: GitHub
      link: https://github.com/example/project
      icon: external
      variant: minimal
---
```

Hero image supports:

- `{ file, alt? }`
- `{ light, dark, alt? }`
- `{ html }`

## Sidebar Frontmatter

Only affects autogenerated sidebar links.

```md
---
title: My page
sidebar:
  label: Short label
  order: 2
  hidden: false
  badge:
    text: New
    variant: tip
  attrs:
    target: _blank
---
```

Fields:

| Field | Type | Behavior |
| --- | --- | --- |
| `label` | `string` | Override sidebar label; defaults to `title`. |
| `order` | `number` | Lower numbers sort earlier. |
| `hidden` | `boolean` | Hide from autogenerated sidebar. |
| `badge` | `string | BadgeConfig` | Add sidebar badge. |
| `attrs` | `Record<string,string|number|boolean|undefined>` | HTML attributes merged with `autogenerate.attrs`. |

Draft pages are excluded from production builds and from autogenerated sidebar groups in production.

## Schema Extension

Extend frontmatter schema in `src/content.config.ts`:

```ts
import { defineCollection } from 'astro:content';
import { z } from 'astro/zod';
import { docsLoader } from '@astrojs/starlight/loaders';
import { docsSchema } from '@astrojs/starlight/schema';

export const collections = {
  docs: defineCollection({
    loader: docsLoader(),
    schema: docsSchema({
      extend: z.object({
        description: z.string(),
        category: z.enum(['tutorial', 'guide', 'reference']).optional(),
      }),
    }),
  }),
};
```

If making a built-in optional field required, update every existing page before relying on the build.
