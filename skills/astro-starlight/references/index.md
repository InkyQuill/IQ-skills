## English Source Pages

Start here:

- `index.mdx`: Starlight overview and landing page.
- `getting-started.mdx`: create project, start dev server, add content, update, troubleshoot.
- `manual-setup.mdx`: add Starlight to an existing Astro project.
- `environmental-impact.mdx`: performance/eco guidance.

Guides:

- `guides/project-structure.mdx`: file layout.
- `guides/pages.mdx`: content pages, custom Astro pages, `StarlightPage`, `AnchorHeading`.
- `guides/authoring-content.mdx`: Markdown, MDX, Markdoc, Expressive Code, asides, footnotes, details.
- `guides/sidebar.mdx`: default, manual, autogenerated, badges, attributes, i18n, collapsed groups.
- `guides/site-search.mdx`: Pagefind exclusions and alternate providers.
- `guides/i18n.mdx`: locales, root locale, fallback content, UI translations, current locale.
- `guides/customization.mdx`: logo, sitemap, page layout, TOC, social links, edit links, 404, fonts.
- `guides/css-and-tailwind.mdx`: custom CSS, cascade layers, Tailwind, theming.
- `guides/overriding-components.mdx`: component override workflow.
- `guides/route-data.mdx`: route middleware and page data customization.

Components:

- `components/using-components.mdx`: MDX/Markdoc import rules and built-ins.
- `components/asides.mdx`, `badges.mdx`, `cards.mdx`, `card-grids.mdx`, `link-cards.mdx`, `link-buttons.mdx`, `tabs.mdx`, `steps.mdx`, `file-tree.mdx`, `icons.mdx`, `code.mdx`.

Reference:

- `reference/configuration.mdx`: full `starlight()` config and content collection loaders/schemas.
- `reference/frontmatter.md`: page frontmatter fields and schema extension.
- `reference/overrides.md`: override component names and props.
- `reference/route-data.mdx`: `starlightRoute` object and route middleware helpers.
- `reference/plugins.md`: plugin hook API.
- `reference/icons.mdx`: supported icons and `StarlightIcon`.

Resources:

- `resources/plugins.mdx`: official and community plugins/tools.
- `resources/themes.mdx`: community themes.
- `resources/showcase.mdx`: showcase sites.
- `resources/community-content.mdx`: articles, recipes, videos.

## Quick Diagnostics

| Symptom | Likely reference |
| --- | --- |
| Build complains about docs collection | [configuration.md](configuration.md), [content.md](content.md) |
| Page not visible in sidebar | [sidebar.md](sidebar.md), [frontmatter.md](frontmatter.md) |
| Search indexes private content | [search.md](search.md), [frontmatter.md](frontmatter.md) |
| Locale route/fallback looks wrong | [i18n.md](i18n.md) |
| CSS change breaks dark mode | [customization.md](customization.md) |
| Custom page needs Starlight layout | [content.md](content.md), [route-data-overrides.md](route-data-overrides.md) |
| Plugin options unknown | [plugins.md](plugins.md) plus plugin README/current docs |
