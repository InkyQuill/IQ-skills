# Configuration Reference

Use for `starlight({ ... })` options in `astro.config.*` and collection config in `src/content.config.ts`.

Source docs: `reference/configuration.mdx`, `docs/astro.config.mjs`, `docs/src/content.config.ts`.

## Minimal Config

```js
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';

export default defineConfig({
  integrations: [
    starlight({
      title: 'My docs site',
    }),
  ],
});
```

## Common Options

| Option | Type / shape | Notes |
| --- | --- | --- |
| `title` | `string | Record<string,string>` | Required. Object keys are BCP-47 tags for multilingual titles. |
| `description` | `string` | Default meta description when page frontmatter omits it. |
| `logo` | `{ src }` or `{ light, dark }` plus `alt`, `replacesTitle` | Use local repo paths or public paths. |
| `tableOfContents` | `false | { minHeadingLevel, maxHeadingLevel }` | Default includes H2-H3. |
| `editLink` | `{ baseUrl }` | Final URL is `baseUrl + current page path`. |
| `sidebar` | `SidebarItem[]` | Links, groups, autogenerated directories. See [sidebar.md](sidebar.md). |
| `locales` | `{ [dir]: { label, lang?, dir? } }` | Enables i18n. `root` serves default locale without prefix. |
| `defaultLocale` | `string` | Must match a `locales` key. Optional for root default. |
| `social` | `{ icon, label, href }[]` | Icon names must be valid Starlight icons. |
| `customCss` | `string[]` | Local CSS files or installed CSS packages. |
| `markdown` | `{ headingLinks?, processedDirs? }` | Extra Starlight Markdown processing directories. |
| `expressiveCode` | `boolean | options` | Code block rendering; false disables. |
| `pagefind` | `boolean | PagefindOptions` | Default search provider. Cannot be enabled with `prerender: false`. |
| `prerender` | `boolean` | Default true for Starlight pages. |
| `head` | `{ tag, attrs?, content? }[]` | Static head tags; not Astro-processed. |
| `lastUpdated` | `boolean` | Git-based footer date. |
| `pagination` | `boolean` | Previous/next footer links. |
| `favicon` | `string` | Public favicon path. |
| `titleDelimiter` | `string` | Default `|`. |
| `disable404Route` | `boolean` | Use custom `src/pages/404.astro`. |
| `routeMiddleware` | `string | string[]` | Starlight route data middleware, not Astro middleware. |
| `components` | `Record<string,string>` | Component override paths. |
| `plugins` | `StarlightPlugin[]` | Starlight plugin instances. |
| `credits` | `boolean` | Footer "Built with Starlight" link. |

## Sidebar Item Shape

```ts
type SidebarItem =
  | string
  | ({ translations?: Record<string, string>; badge?: string | BadgeConfig } & (
      | { link: string; label: string; attrs?: Record<string, string | number | boolean | undefined> }
      | { slug: string; label?: string; attrs?: Record<string, string | number | boolean | undefined> }
      | { label: string; items: SidebarItem[]; collapsed?: boolean }
    ))
  | {
      autogenerate: {
        directory: string;
        collapsed?: boolean;
        attrs?: Record<string, string | number | boolean | undefined>;
      };
    };
```

Badge config:

```ts
interface BadgeConfig {
  text: string;
  variant?: 'note' | 'tip' | 'caution' | 'danger' | 'success' | 'default';
  class?: string;
}
```

## Content Collections

```ts
import { defineCollection } from 'astro:content';
import { docsLoader, i18nLoader } from '@astrojs/starlight/loaders';
import { docsSchema, i18nSchema } from '@astrojs/starlight/schema';

export const collections = {
  docs: defineCollection({ loader: docsLoader(), schema: docsSchema() }),
  i18n: defineCollection({ loader: i18nLoader(), schema: i18nSchema() }),
};
```

Rules:

- Use `docsLoader()` for Starlight docs pages.
- Use `docsSchema()` for docs frontmatter.
- Use `i18nLoader()` and `i18nSchema()` only when the project needs UI translation files.
- Extend schemas with `extend`; do not replace them.

## Official Docs Config Pattern

The Starlight docs site uses:

- `site` and `trailingSlash`.
- `logo.light`, `logo.dark`, `replacesTitle`.
- `lastUpdated`, `editLink`, `social`, `head`, `customCss`.
- `locales` including `root`, language keys, and `dir: 'rtl'` for Persian.
- Manual sidebar groups with autogenerated directories.
- `expressiveCode` language config.
- `starlight-links-validator` only when `CHECK_LINKS` is set.

Use this as a pattern for complex docs, not as a default for small sites.
