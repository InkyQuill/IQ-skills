# Sidebar Navigation

Use for default sidebar behavior, manual navigation, autogenerated groups, badges, attributes, i18n labels, and collapsed groups.

Source docs: `guides/sidebar.mdx`, `reference/configuration.mdx#sidebar`, `reference/frontmatter.md#sidebar`.

## Default Sidebar

Without manual `sidebar` config, Starlight generates navigation from `src/content/docs/`.

Example:

```txt
src/content/docs/
  constellations/andromeda.md
  constellations/orion.md
  stars/betelgeuse.md
```

Generates groups from directories and labels from each page's `title`.

Use page frontmatter to tune autogenerated entries before reaching for manual config:

```md
---
title: Andromeda
sidebar:
  label: Andromeda Galaxy
  order: 1
---
```

## Manual Links

Internal docs pages use `slug`, relative to `src/content/docs/` and without extension:

```js
starlight({
  sidebar: [
    { slug: 'constellations/andromeda' },
    'constellations/orion',
  ],
})
```

External or non-docs links use `label` and `link`:

```js
starlight({
  sidebar: [
    { label: 'Shop', link: '/shop/' },
    { label: 'GitHub', link: 'https://github.com/example/project' },
  ],
})
```

Do not use `slug` for external links.

## Groups

```js
starlight({
  sidebar: [
    {
      label: 'Guides',
      items: [
        'guides/install',
        'guides/configuration',
        {
          label: 'Advanced',
          items: ['guides/performance', 'guides/security'],
        },
      ],
    },
  ],
})
```

Groups can contain links, nested groups, and autogenerated entries.

## Autogenerated Groups

```js
starlight({
  sidebar: [
    {
      label: 'Reference',
      items: [{ autogenerate: { directory: 'reference' } }],
    },
  ],
})
```

Rules:

- `directory` is relative to `src/content/docs/`.
- Autogenerated pages sort by file ID alphabetically unless `sidebar.order` is set.
- Use a group with `items: [{ autogenerate: ... }]`; do not assume `autogenerate` can replace every group shape.
- File names starting with `_` are ignored by `docsLoader()`.

## Frontmatter Controls

```md
---
title: Migration
sidebar:
  label: Migrate
  order: 20
  hidden: false
  badge:
    text: v2
    variant: note
  attrs:
    rel: nofollow
---
```

`sidebar.hidden: true` hides from autogenerated groups but keeps the route.

## Badges

String badge:

```md
---
title: New API
sidebar:
  badge: New
---
```

Object badge:

```js
{ slug: 'guides/migration', badge: { text: 'Experimental', variant: 'caution' } }
```

Built-in variants: `note`, `tip`, `caution`, `danger`, `success`, `default`. Use `class` only with a defined custom CSS class.

## Attributes

Manual link:

```js
{
  label: 'NASA',
  link: 'https://www.nasa.gov/',
  attrs: { target: '_blank', rel: 'noopener' },
}
```

Autogenerated group attributes:

```js
{
  items: [
    {
      autogenerate: {
        directory: 'reference',
        attrs: { class: 'reference-link' },
      },
    },
  ],
}
```

Page `sidebar.attrs` merges with `autogenerate.attrs`.

## Internationalized Sidebar

For manual labels, use `translations` keyed by locale language tag:

```js
{
  label: 'Start Here',
  translations: { fr: 'Commencez ici', 'pt-BR': 'Comece Aqui' },
  items: [
    {
      label: 'Getting Started',
      translations: { fr: 'Bien demarrer' },
      slug: 'getting-started',
    },
  ],
}
```

For localized content, keep matching paths across locales so internal links and fallback behavior line up.

## Collapsing Groups

```js
{
  label: 'Archive',
  collapsed: true,
  items: ['archive/v1', 'archive/v2'],
}
```

Collapse autogenerated subgroups:

```js
{
  label: 'Reference',
  items: [{ autogenerate: { directory: 'reference', collapsed: true } }],
}
```

## Troubleshooting

| Symptom | Check |
| --- | --- |
| Page missing from autogenerated sidebar | `sidebar.hidden`, `draft`, file under correct directory, file starts with `_`. |
| Manual slug fails | Slug is extensionless path under `src/content/docs/`. |
| External link broken | Use `{ label, link }`, not `slug`. |
| Order wrong | Add `sidebar.order`; lower appears earlier. |
| Locale label untranslated | Add `translations` for manual sidebar items or localized page title/frontmatter. |
